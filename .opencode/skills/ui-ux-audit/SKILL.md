# UI UX Audit
Inspect the existing implementation before changing it. Analyze layout, navigation, hierarchy, spacing, typography, information density, interaction, consistency, accessibility and responsive behavior.
Identify unnecessary elements, weak hierarchy, duplication, excessive cards, poor alignment and generic patterns.
Preserve functionality unless explicitly asked otherwise.
