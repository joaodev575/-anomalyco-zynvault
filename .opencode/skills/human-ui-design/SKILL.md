# Human UI Design
Design the product as a real commercial application. Avoid generic AI-generated visual patterns.
Avoid excessive cards, gradients, glassmorphism, shadows, blur, giant headings, badges, icons, decoration and empty space.
Prefer strong hierarchy, intentional spacing, restrained colors, precise typography, meaningful alignment, controlled density and distinctive composition.
Every visual decision must have a reason.
